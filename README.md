# Triple Draft Football (working title)

Retro Bowl-style arcade football meets All-22-style drafting: build a full 22-player lineup from
three random options per round, head-to-head online, then play each other.

Status: **Milestone 1 (skeleton + data)** done. See `CLAUDE.md` for architecture, commands,
decisions and milestone status, and `docs/spec.md` for the full spec.

```bash
pnpm install
pnpm test          # unit tests
pnpm data:report   # rebuild the draft pool and print the balance report
```
